Mermaid diagram examples

Use these practical starting points for software documentation, product planning, architecture, and team communication. Copy a block into Mermaid Studio, edit the labels, and export the finished diagram.

Open Mermaid editorRead the editor guide

Tip: Mermaid is indentation-friendly, but exact spacing is not required for most diagram types. Start with the first declaration line and keep identifiers short and unique.

Flowchart example

Model a product decision, process, approval path, or troubleshooting sequence with nodes and labeled arrows.

flowchart TD
  request[New request] --> review{Complete?}
  review -->|Yes| prioritize[Prioritize work]
  review -->|No| clarify[Ask for details]
  clarify --> review
  prioritize --> build[Build and test]
  build --> release([Release])

Sequence diagram example

Show messages exchanged between a user, a browser application, and local browser storage.

sequenceDiagram
  actor User
  participant App as Mermaid Studio
  participant Store as Browser storage
  User->>App: Edit diagram source
  App->>App: Render live preview
  App->>Store: Autosave project
  Store-->>App: Confirm local save
  App-->>User: Show saved status

Class diagram example

Describe application entities, their properties, methods, inheritance, and composition relationships.

classDiagram
  class Project {
    +String name
    +Diagram[] diagrams
    +save()
  }
  class Diagram {
    +String title
    +String source
    +render()
    +export(format)
  }
  Project "1" *-- "many" Diagram
  Diagram <|-- Flowchart
  Diagram <|-- SequenceDiagram

State diagram example

Explain how a document, order, ticket, or interface moves between defined states.

stateDiagram-v2
  [*] --> Draft
  Draft --> Review: submit
  Review --> Draft: changes requested
  Review --> Approved: approve
  Approved --> Published: publish
  Published --> Archived: archive
  Archived --> [*]

Entity relationship diagram example

Document a data model with entities, attributes, keys, and cardinality.

erDiagram
  PROJECT ||--o{ DIAGRAM : contains
  DIAGRAM ||--o{ COMMENT : has
  PROJECT {
    string id PK
    string name
    datetime updated_at
  }
  DIAGRAM {
    string id PK
    string project_id FK
    string title
    text source
  }
  COMMENT {
    string id PK
    string diagram_id FK
    text body
    boolean resolved
  }

Gantt chart example

Plan milestones and dependencies across a small launch or delivery schedule.

gantt
  title Documentation launch
  dateFormat YYYY-MM-DD
  section Product
  Editor polish      :done, polish, 2026-08-18, 3d
  Export testing     :active, export, after polish, 2d
  section Content
  Write guide        :guide, 2026-08-18, 2d
  Publish examples   :examples, after guide, 1d
  Submit sitemap     :milestone, after examples, 0d
