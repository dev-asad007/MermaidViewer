Mermaid Studio turns plain-text Mermaid syntax into diagrams as you type. It requires no account, sends no diagram data to a backend, and gives you local projects, version history, comments, folder access, and high-quality exports.

What is a Mermaid diagram?

Mermaid is a text-based diagram syntax. Instead of dragging boxes around a canvas, you describe nodes and relationships in plain text. The same source can live next to your code, documentation, or project notes, which makes diagrams easier to review and update.

A basic left-to-right flowchart looks like this:

flowchart LR
  idea[Idea] --> review{Ready?}
  review -->|Yes| build[Build]
  review -->|No| revise[Revise]
  revise --> review
  build --> ship[Ship]

Open the Mermaid examples collection for copy-ready flowchart, sequence, class, state, entity relationship, and Gantt examples.

Use the code editor

The editor provides line numbers, syntax colors, bracket matching, autocomplete, folding, search, lint markers, undo, and redo. Mermaid keywords, arrows, labels, values, and comments use separate colors in both light and dark modes.

  • Press Ctrl/Cmd + F to search inside the source.
  • Press Ctrl/Cmd + / to comment or uncomment selected Mermaid lines.
  • Use the fold gutter or Fold all button to hide long sections and subgraphs.
  • Choose Quick fix to normalize common copied-text and arrow problems.
Your source stays private.

Mermaid Studio renders with JavaScript in the current browser tab. It does not send diagram text to an application server.

Manage multiple local projects

The Projects selector keeps up to 20 browser projects available for quick switching. A project can contain multiple diagrams, working notes, review comments, settings, and history. Use New to create a clean workspace, Duplicate to branch an existing project, or Delete to remove a browser copy.

Browser storage is convenient but should not be your only backup. Use Save project regularly to download a portable .mstudio file. Opening that file later restores its diagrams and project information.

Open and save a local folder

On Chromium-based browsers over HTTPS, Choose folder can read supported Mermaid files from a folder you select. The app only receives access after the browser asks for your permission. Connected source files can be saved back to that folder when autosave is enabled.

Folder support recognizes .mmd, .mermaid, and .txt source files. If your browser does not support direct folder access, the portable project and download features still work.

Autosave and version history

Autosave stores the active project in browser storage after an edit. Mermaid Studio also keeps local snapshots so you can restore an earlier version, label an important checkpoint, delete a single snapshot, or clear the current diagram’s history. History is local to the browser unless included in a portable project file.

Comments and working notes

The Comments panel supports lightweight review threads for each diagram. Add a comment, resolve it when work is complete, reopen it later, or delete it. Working notes are useful for decisions, follow-up items, and context that should travel with the project file.

Frequently asked questions

Is Mermaid Studio free?

Yes. The editor is free to use in the browser and has no login, subscription, or paid feature gate.

Does the editor use AI?

No. Mermaid Studio is a direct syntax editor and renderer. It does not include an AI mode or send prompts to an AI service.

Where are projects stored?

Autosaved projects are stored in your browser. Portable project files and exports are saved to locations you choose on your computer.

Can I use it on Windows, macOS, and Linux?

Yes. The core editor and downloads work in modern browsers on all three platforms. Direct folder access depends on browser support.

Can I use exported diagrams commercially?

The app does not add a watermark or usage restriction to your exports. You remain responsible for the content and any third-party material you include.
