Plain-language policy

Your diagrams stay on your device

Mermaid Studio is a static, local-first web application. It has no account system, application database, analytics tracker, advertising SDK, or AI processing service.

No loginNo diagram uploadsNo analyticsNo ads

Effective date: August 18, 2026

Short version

Your diagram source, project names, comments, notes, and history are processed in your browser. They are not sent to an application backend because Mermaid Studio does not operate one.

Information Mermaid Studio does not collect

Mermaid Studio does not ask for your name, email address, password, payment information, or profile. The application does not intentionally collect diagram source, project contents, filenames, notes, comments, export settings, or usage analytics.

The public website is hosted by GitHub Pages. Like most web hosts, GitHub may process technical request information needed to deliver the site, such as an IP address, user agent, requested URL, or security logs. That hosting activity is governed by GitHub’s own policies and infrastructure, not an application database controlled by Mermaid Studio.

Browser storage

When autosave is enabled, projects and settings are stored using browser-provided local storage. This data remains associated with the browser profile and device you are using. Clearing site data, using private browsing, changing browsers, or reinstalling a browser may remove it.

For durable backups, download a portable .mstudio project file or save Mermaid source files to a folder you control.

Local files and folder permissions

If you choose Open, Save, or Choose folder, the browser displays its own file or folder picker. Mermaid Studio can only read or write items you explicitly select and only within the permission boundaries enforced by the browser.

Folder handles may be remembered by supported browsers to make reconnection easier. The browser can ask you to approve access again. You can revoke site permissions through your browser settings.

Exports and downloads

PNG, JPEG, SVG, PDF, Mermaid source, Markdown, and portable project exports are generated on your device. The browser downloads those files to the location configured in your browser or selected through a save dialog.

Private sharing links

The Copy link feature can encode Mermaid source in the URL fragment after the # symbol. URL fragments are normally handled by the browser and are not sent as part of an HTTP request to the web host. Anyone who receives the complete link can read the encoded diagram, so treat the link like a file and share it only with intended recipients.

Third-party code and hosting

The application bundles open-source browser libraries used for Mermaid rendering, code editing, and export. Runtime diagram editing does not require contacting an AI API or application server. The compiled website and static assets are served through GitHub Pages.

Children’s privacy

The application does not knowingly collect personal information from children or adults. Because no account or user-profile system exists, Mermaid Studio does not attempt to determine a visitor’s age.

Security and your responsibility

No browser application can guarantee that locally stored information will never be lost. Keep backups of important projects, keep your browser updated, and avoid placing sensitive information in links you plan to share. Review exported files before forwarding them.

Changes to this policy

If the application’s data handling changes, this page will be updated with a new effective date. A future feature that introduces a backend, analytics, or account system would require a corresponding policy update before release.

Questions and project information

Mermaid Studio is maintained as a public GitHub project. For product usage information, read the Mermaid Studio guide. You can also return to the free Mermaid editor or browse copy-ready Mermaid examples.
